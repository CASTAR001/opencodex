---
name: markdown-link-labels
description: 编写或修订要在 OpenCode 文件预览中阅读的 Markdown 文档时，为外部资料生成能说明用途的原生链接文字。
---

为读者要点开的资料写标准的 `[可读名称](原网址)`。名称尽量回答“点开能看到什么”，沿用写作语言，保留能识别资料的项目名。无需依赖预览插件，也不必把同一个 URL 再重复一遍。

例如，段落讨论“脚注如何返回正文”，已知资料是 Quarto 的文章布局文档时，可写 `[Quarto 的文末注释与页边布局](https://quarto.org/docs/authoring/article-layout.html)`。如果只知道某个 GitHub 仓库的地址，用实际的组织/仓库名；不要仅凭域名编造标题、文章结论或作者。保留原目的地址、参数、片段和作者已有的有效标签。

补充说明可写成 `正文[^note]`，并另起段写 `[^note]: 说明内容。`。只有外链需要介绍时，直接命名链接即可。示例代码、URL 字面量和用户要求原样抄录的内容保持原文。
