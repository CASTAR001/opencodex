# 版本记录

## 0.1.0-alpha.4

- 缩短长会话刻度列，两端向内收，按整个页面的中线对齐。窗口高度改变时自动调整留白与可见条数。

## 0.1.0-alpha.3

- 按会话面板可用高度显示整条刻度，超出可见范围的一侧用三条渐隐刻度提示。鼠标持续悬停在渐隐处可向对应方向浏览，移开即停，点击刻度才跳转。

## 0.1.0-alpha.2

- 按正文左侧的实际留白显示导航。拖窄聊天区时，刻度和预览卡一起收起，留白恢复后可继续跳转和使用原有星标。

## 0.1.0-alpha.1

- 为用户提示与追加提示提供左侧短刻度，支持原位跳转、悬停预览及键盘导航。
- 通过星形按钮为单条提示设置会话内星标，支持重新打开会话后恢复。
- 长历史按需载入，窄窗保留细轨。附可离线使用的交互预览。
