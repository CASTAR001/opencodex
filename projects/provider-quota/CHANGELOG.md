# Changelog

## 0.1.0-alpha.8

可在剩余额度页调整服务商卡片顺序，偏好通过宿主全局存储保存，用量筛选器同步排序。

## 0.1.0-alpha.7

同一服务商可以同时配置多个连接。钱包按官方查询地址和凭据分组，同一组只展示一次，不同组分开标注连接名称。跨站共用凭据时仍须手动选择查询目标。

## 0.1.0-alpha.6

MiMo 改用小米官方接口查询中国区个人套餐的当前剩余额度，沿用进入页面自动查询和手动刷新的交互。移除了基于本机用量推算 Credits 的卡片和历史查询，用量页支持按 MiMo 筛选宿主记录的 Token。

## 0.1.0-alpha.5

修复 MiniMax 可选字段缺失造成的本地 RPC 500。额度窗口统一显示剩余值和重置时间，MiMo 卡片缩小顶部留白。新建对话的钱包位于草稿内容区右上角，在顶部标签、侧边标签、收件箱和窄窗中均可点击。

## 0.1.0-alpha.4

会话和新建对话均可通过钱包图标打开额度。默认展示剩余额度，并在每次进入时查询已配置的服务商。Kimi 和 MiniMax 展示接口提供的窗口、计数和重置时间，关闭弹窗后释放读数。

## 0.1.0-alpha.3

- 用量统计的筛选器和账户额度的刷新按钮与页签同排显示，窄窗口可自动折行。

## 0.1.0-alpha.2

- 顶栏改为统计图标；可见服务商随模型或 MCP 配置增删而更新。
- MiMo 按 Standard 月度套餐离线估算今天和近七天占比。
- MiniMax 支持读取安装前的 Code Mode 媒体调用，并标注逐笔扣额的数据边界。

## 0.1.0-alpha.1

- 从对话顶栏一键打开用量统计与手动额度查询。
- 跨会话历史、时段和模型服务商筛选，另列 MiniMax MCP 的生图与语音调用。
- 六家服务商的查询能力说明、API Key 连接识别、区域选择、快照时间和独立错误状态。
