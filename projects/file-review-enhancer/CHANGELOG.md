# Changelog

## 0.1.0-alpha.4 · 桌面主进程加载

- 将阅读器和 Markdown 解析库的初始化延后到窗口启动，修复扩展列表中的 `document is not defined`。服务端继续登记链接写作技能。

## 0.1.0-alpha.2 · 原文件标签

- 从原生文件树打开 Markdown 后直接在当前标签阅读，保留源码切换与独立阅读入口。
- 提示块和已完成待办使用主题甜橙色，脚注有可聚焦、可悬停的圆形点击区。
- 网页链接支持悬停下划线、左键打开、右键复制网址。文件代码块沿用对话正文的排版与代码块插件。

## 0.1.0-alpha.1 · 隔离原型

- 在右侧栏独立标签中阅读工作区 Markdown，按栏宽调整标题、段落、表格和公式。
- 支持 GFM 脚注、重复引用和键盘回链。裸外链按地址生成可读名称，有名链接沿用原文。
- 随包提供 `markdown-link-labels`，用标准链接文字把资料简介保存在文档里。
- 添加一篇可复跑的中文长文和 Markdown 解析用例，基线为 OpenCode Desktop 2.3.2。
