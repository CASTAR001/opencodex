# 对话正文增强

适用于 OpenCode Desktop 2.4.0 的经典和新版时间线。工具调用折叠摘要前显示甜橙色圆点。任务成功结束后，第一个最终输出片段前显示带横线的粗体「已完成」。判定依据是会话中的成功结束记录、助手消息的完成状态和文本片段位置。运行中、失败、中断以及缺少结束记录的旧对话沿用宿主显示。

助手正文在消息写完后检查中文标点紧贴强调符、裸链接与下一句相连这两种情况。修复限于能对应回原稿的文本与链接。代码示例、显式链接地址、原生消息复制、输入框和文件内容由宿主管理。重复且无法区分出处的字串保留原样。标题和正文继承原生字号。

安装时运行 `npm pack --ignore-scripts`，将包解开到 OpenCode 全局插件目录的 `markdown-presentation/`。从源码复测可运行 `npm ci`、`npm test` 和 `npm run build`。本版在 macOS 的 2.4.0 出厂渲染器上验证，选择器随宿主时间线结构变化需要复核。
