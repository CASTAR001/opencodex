# Markdown 阅读器

OpenCode Desktop 的右侧栏 Markdown 阅读插件。在右侧文件树中点开工作区里的 `.md`，原文件标签会显示阅读排版。工具栏可以切换预览与源码。「＋ → 阅读 Markdown 文件…」仍可另开阅读标签。当前原型只读。

## 阅读样张

《潮间带的六小时》含两条脚注、一条重复引用、五列表格、公式、代码和三种外链写法。在第一段和「把一条记录留给下一班人」末尾都可以进入同一条注释。文末的 ↩1、↩2 分别返回正文中的两个出处。[长文原稿](examples/tidal-notebook.md)

沿用 OpenCode 自带的链接前置图标。裸仓库地址显示为 `作者/仓库`；其他裸网址显示域名，有可读路径末段时附上简短文字。仅有文章编号时显示域名。完整地址留在链接目标中。作者写下的链接文字会原样保留。随插件提供的 skill 引导模型把资料用途直接写成标准 Markdown，例如 `[Quarto 的注释与文章布局](https://quarto.org/docs/authoring/article-layout.html)`。这个简介在其他阅读器中也能显示。[随附 skill](skills/markdown-link-labels/SKILL.md)

网页链接在悬停或键盘聚焦时显示下划线。左键在系统浏览器打开，右键沿用 OpenCode 的「复制链接」，可保留完整网址、查询参数和页内锚点。脚注的浅色圆形既是编号背景，也是点击区域。文末回链在悬停和键盘聚焦时显示底色与下划线。提示块左边线与已完成待办使用主题强调色。勾选框与首行文字居中对齐，长条目换行后仍贴齐首行。待办显示文件中 `- [x]` 与 `- [ ]` 的状态。代码沿用会话的渲染器；启用 02 Code Block Enhancer 时，两处使用同一套代码块工具栏。

右栏宽度变化时，表格会随之调整。文字按内容换行，较长的路径、行内代码或链接文字可以在列内折行。窄栏会收紧单元格左右留白。列数很多或公式需要更多空间时，可以在表格内左右滚动比较。

## 导出与混排

在右栏打开 Markdown 文件，点击阅读页右上角的「导出为」图标，选择 HTML、PDF 或 Word。独立阅读标签也有同一入口。上下键选择格式，Esc 收起菜单。原生「⋯ → 下载」仍保存 Markdown 原稿。三种导出都处理整份文档，代码块的窗口高度、换行按钮和选区不会限制输出范围。

HTML 以内联样式和 MathML 离线展示。PDF 使用桌面版的隐藏打印页与系统保存对话框。Word 需要本机可用的 Pandoc 3（macOS 的 Homebrew 或 Windows 的 Pandoc 安装器均可）。生成的段落、表格、脚注和数学公式可继续编辑。重复脚注链接到同一条注释。工作区内可读且大小合适的 PNG、JPEG、GIF、WebP 和 SVG 图片会嵌入，其他图片显示替代文字。SVG 转为 PNG。代码保留完整文本，导出的网页链接保留目标与显示名。二进制文件在选择位置并转换成功后写入。

阅读器和导出解析中文标点紧贴强调符的写法，例如 `**结论。**紧接下一句`。裸网址遇到中文句末标点和紧接的中文时会在标点前结束，显式 Markdown 链接仍以作者写下的地址为准。

## 开发与验收

从源码安装时，先运行 `npm ci` 和 `npm pack`。将生成的归档解开，把其中的 `package/` 目录作为 `~/.config/opencode/plugins/file-review-enhancer/` 使用，保留 `dist/`、`src/server.js` 和 `skills/` 的相对位置。

在本仓库运行 `npm ci` 和 `npm test`。测试会先构建 `dist/gui-experimental.cjs`，并验证它能在没有 DOM 的 Desktop 主进程读取。阅读器在窗口中初始化，独立的服务端入口负责登记 skill。宿主升级后需要复测这两个入口。

2.3.2 的文件树直接打开内置标签，内置 Markdown 分支优先于第三方 `FileViewer`。插件从公开的 `session.panel.end` 插槽取得所属会话和文件模型，在同一右栏内匹配内置预览容器及其路径，再挂载阅读视图。文件标签、文件监听、预览／源码切换和查找由宿主负责。原生视图仍挂载在后台，长文有额外的解析和内存开销。宿主改动这些 DOM 标记时，匹配失败会显示原生预览。文件树已在 macOS 2.3.2 和 2.4.0 隔离验证。导出功能以 2.4.0 为基线。

协调仓的 `tests/file-review/browser.mjs` 重建离线对照，`tests/file-review/desktop_probe.py` 使用临时工作区、出厂渲染器及真实文件树复测入口。文件编辑留给后续阶段。[开源参考与接入计划](MARKDOWN_PREVIEW_PLAN.md)
