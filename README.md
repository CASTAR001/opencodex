# Project Sidebar

OpenCode Desktop 侧边标签页的项目会话树。项目行显示仓库的本地目录，点击文件夹收起或展开，点击下方标题打开对应会话。项目栏右上角的列表按钮可切回原生侧栏，再点「返回项目树」切回。

直接打开 [交互预览](preview/index.html)。预览在本地运行，项目、路径、搜索和新会话都使用示例数据。正式插件复用宿主已有的新会话和搜索入口。

## 安装与使用

在 macOS 上，将本目录中的 `package.json` 和 `gui-experimental.cjs` 放到 `~/.config/opencode/plugins/project-sidebar/`。OpenCode Desktop 加载插件后，在「设置 → 偏好设置 → 界面布局」中选择「侧边标签页」即可看到项目树。

## 文件夹右键菜单

- **隐藏文件夹**把目录移到侧栏底部默认收起的「隐藏文件夹」。展开后右键选择「恢复到项目列表」。本机按服务与目录保存选择，再次打开仍然生效。
- **快速关闭项目…**先显示项目的绝对路径。确认后调用 Desktop 自带项目菜单的「关闭」，从当前客户端的已用项目列表移除。磁盘文件、会话和权限保留。再次打开项目或其会话可以返回项目树。
- **原生入口**在「设置 → 实验 → 整理垂直侧边栏」选择「项目」。回到侧栏，点击插件「项目」标题右侧的列表图标切回原生视图。展开项目分组，右键项目行，或点击该行的「更多选项 → 关闭」。原生入口一步生效。
- 2.3.2 的 GUI SDK 没有按目录关闭项目或撤销信任的命令。快捷关闭在单服务、原生项目行已经渲染且可以唯一定位时可用。重名、项目分组未展开、未列出的历史目录等情况可改用原生入口。旧版共享的 global 项目具有客户端别名，也可能使匹配不可用。

## 路径与会话

- 本机内置服务使用 Desktop 主进程通过 GUI IPC 提供的用户主目录。例如主目录为 `/Users/demo` 时，`/Users/demo/work/opencodex` 显示为 `~/work/opencodex`。`/Users/demo2`、外置卷和远程服务保留自己的路径。悬停能看到完整地址。
- 以服务和项目根目录区分项目，以服务和会话 ID 打开会话。同名目录、同名会话可以分别选择。已知 Git 项目使用规范根目录，普通文件夹使用会话的工作目录。
- 读取项目清单、每个服务最近 500 个顶层会话及已经载入的会话信息。每组先显示 5 条；当前会话始终可见，主动收起项目后可再展开。更早的历史可通过原生搜索打开。
- 列表不读取消息正文。项目和会话信息由宿主提供，重命名、移动、归档等事件合并刷新索引。展开状态随这次侧栏挂载保留。

## 开发与验证

`npm ci` 后运行 `npm run build` 和 `npm test`。构建同时生成插件入口和离线预览，测试检查两者是否匹配源码。

已针对 OpenCode Desktop 2.3.2 验证。数据来自 GUI SDK 的服务器和标签接口，通过 `ctx.tabs.open` 选中会话。该版本没有公开的侧栏列表替换插槽；`src/host.js` 定位 `vertical-tabs-mount` 下的原生列表，挂载独立的项目树。顶部标签页、收件箱和移动抽屉保留宿主界面。OpenCode 升级时应复核这处宿主结构。找不到对应列表时保留原布局。

隔离宿主测试在协调仓库的 `tests/project-sidebar`。它使用官方渲染器、本地临时 sidecar 和合成项目。桌面 IPC 由测试窗口模拟，主目录提供方另有单元测试。
