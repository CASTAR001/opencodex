# 对话文件右栏临时修复

适用于 OpenCode Desktop **2.3.2** 的双栏布局。点击对话正文中的本地文件链接或宿主识别的行内代码路径时，使用原生「切换侧栏」命令展开收起的右栏。文件解析、同名文件选择及行号定位继续由 OpenCode 处理。键盘 Enter 也可打开已聚焦的链接。

每次加载时检查 Desktop 版本。升级到其他版本后不注册界面组件和事件监听。扩展列表的开关仍可手动关闭。插件只依赖 GUI 入口，没有后台进程或持久化设置。

右栏收起时，先展开，再打开文件。对能在工作区核实的普通路径，使用原生文件选择器的精确打开接口。带行号、HTML 或需要搜索匹配的路径交给原生链接处理。外部网址、窄屏单栏和原生附件下载沿用宿主行为。

安装时将 `package.json` 和 `gui-experimental.cjs` 放入全局插件目录下的 `session-file-reveal/`。要完全卸载，移出该目录即可。
