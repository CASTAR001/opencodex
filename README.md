# Prompt Navigation · 提示词刻度导航

OpenCode Desktop 2.3.2 的独立 GUI 插件。会话左边缘的每条短横线代表一条已送达的用户提示，包括同一任务中的追加提示。正文沿用原本的宽度。

- 点击短线，跳到对应提示。上下滚动正文时，加长的刻度标出阅读位置。
- 悬停显示提示文字。将指针移进浮层，点击星形可添加或取消本条星标。星标刻度显示主题强调色和小点。
- 用 Tab 进入刻度，在轨内按 ↑ / ↓ 或 Home / End 选择提示，Enter 跳转，→ 聚焦星标，Esc 关闭浮层。小屏可点按刻度后再点星标。
- 刻度过多时，在刻度区域滚动可查看其余提示。会话内按消息 ID 记星标，宿主负责保存。

## 本地预览

运行 `npm ci`、`npm run build`、`npm test`。运行 `npm run preview` 后直接打开 `preview/index.html`。示例内嵌脚本，使用合成对话和独立的预览星标。桌面插件只使用宿主的 GUI、Solid 和 Effect 运行时。

## 兼容范围

读取当前会话、消息分页和会话星标存储使用 GUI API。2.3.2 的标题插槽在窄窗会卸载，窄窗由窗口插槽接手。左侧定位依赖 `session-chat-panel`，阅读位置依赖可见的消息元素。跳转按原生选择器的顺序载入目标页，再用 Desktop 内存路由的消息锚点交给虚拟时间线。以上布局与锚点在宿主升级时均需复测。未找到宿主容器时跳过挂载。插件独立于任务折叠功能。

开发验证使用协调仓的 `tests/prompt-navigation/desktop_probe.py <2.3.2 源码归档> classic` 和 `next` 模式；此脚本从已安装的官方应用读包，在独立临时目录中加载测试会话。
